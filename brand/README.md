# gated-exec remediation brand

The app icon and logo follow the brand format of [fresnel](https://github.com/kajisho5/fresnel). The Liquid Glass `.icon` bundle (Apple Icon Composer format) is generated by the fresnel CLI ([fresnel-icon](https://www.npmjs.com/package/fresnel-icon), MIT) from `src/spec.json` and two layer SVGs.

The three products ZES / ZET / GER share the same composition and differ only in shape and accent color. Back = an arched gate; front = ✓ (an approved remediation).

## Regenerating

```bash
cd brand
python3 src/layers.py ger                  # layer SVGs (needs shapely; only when the shape changes)
python3 src/wordmark.py "gated-exec remediation"   # wordmark (needs fonttools and Inter Display SemiBold; only when the text changes)
npm ci && npm run build                     # writes the .icon and all assets below
```

`npm ci` does not run install scripts because of `ignore-scripts=true` in `.npmrc`. fresnel-icon 0.2.2 does not export its renderer as a public API, so `build.mjs` builds a module inside `node_modules` from the bundled `dist/cli.js` without the CLI start-up part and loads it. When you upgrade fresnel-icon, check the output visually.

The text in the social images is drawn with a system font, so the pixels vary by environment (the icon, logo and favicon are confirmed to produce the same output from the same input).

## Guidelines (same as fresnel)

- The composition is a background + 2 glass groups. Do not bake highlights or shadows into the layers (they come from the .icon settings)
- Where the platform applies a mask (apple-touch-icon, maskable), use the version without a mask
- Below 24 px, use the icon alone without the wordmark. Minimum 16 px
- The wordmark is `#F5F5F7` on dark backgrounds and `#1D1D1F` on light backgrounds. Write the name in lowercase
- The wordmark typeface is Inter Display SemiBold (SIL OFL 1.1) converted to outlines. Do not use Apple trademarks
